# Jasleen Kaur Portfolio

A clean, minimal, single-page portfolio website built with React and deployable to GitHub Pages.

## Features
- Responsive, professional design
- Smooth scroll navigation
- Sections: Home, Experience, Projects, Skills, Certificates, Contact, Resume
- Minimal dependencies

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start development server:
   ```sh
   npm start
   ```
3. Build for production:
   ```sh
   npm run build
   ```
4. Deploy to GitHub Pages:
   ```sh
   npm run deploy
   ```

---

## Sections
- **Home**: Name, title, social/contact links
- **Experience**: Timeline of career highlights
- **Projects**: Showcase with links
- **Skills**: Grid/badge format
- **Certificates**: Card layout
- **Contact**: Email/phone or mailto form
- **Resume**: Button to Google Drive resume
